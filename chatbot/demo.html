🚀 Quick Start

Step 1: Start the Flask backend

cd chatbot && python app.py

Step 2: Add chatbot to your website

Copy these lines to your HTML <head>:

<link rel="stylesheet" href="path/to/chatbot/styles.css">

Before closing </body>, add:

<div id="chatbot-widget"></div>
<script src="path/to/chatbot/widget.html"></script>
<script src="path/to/chatbot/script.js"></script>

Step 3: Configure your OpenAI API key

Create chatbot/.env with your API key:

OPENAI_API_KEY=sk-your-key-here

💡 Pro Tips

  • Edit the system prompt in app.py to customize chatbot knowledge
  • Customize colors by editing CSS variables in styles.css
  • The theme preference is saved to localStorage
  • Chat history is kept for the current session
  • Use CORS headers for cross-origin requests
